# Lessons (append after every carousel)

## 2026-10-07 Money Moves (first run)

- Cloud sessions block most .gov, bank, carrier and design sites, and the Higgsfield CDN. Web search restricted to the primary domain still works for verification. Real page screenshots need `capture_sources.mjs` on a machine with access.
- Preload every font face before mount. Otherwise `fit()` measures the fallback font and shrinks the hook by about 30%.
- Chromium refuses file:// images as CSS masks. Pass the distress texture as a data URI.
- Bottom-anchor the hook on the red rail with a height fit. Top-anchored hooks left half the frame empty.
- Keep tip titles still in IG loops. A rising title overlaps the action line on frame 0.
- Grid crop: IG shows 4:5 posts as 3:4 on the profile grid, so keep 84px side margins.
- The AI caught an arithmetic slip in a sample bill we wrote. Keep it and disclose it. Honest surprises beat planted ones.
- Rendering costs about 0.6s per 1080p frame per worker. `--jobs 4` on 4 cores.
- Both platforms cap hashtags at 5 now.
- Anti-slop pass caught two ember elements per tip slide (title accent plus orange highlighter in the proof card). Card highlights are now red underlines, the partner color. One ember thing per frame.
- `pkill -f render.mjs` also kills the shell running it. Kill render jobs by PID.
- Nigel's call after the first render: too much. He wants downloadable individual PNGs, light or vivid backgrounds (no black), no TikTok renders. Those are now the defaults.
