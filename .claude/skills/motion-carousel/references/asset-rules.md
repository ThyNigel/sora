# Asset sourcing rules

- Proof is only: official source text or screenshots, real AI outputs, Nigel's own app or account screens with every account number, balance and income figure blurred or replaced.
- Higgsfield, image generation and `plates.py` are atmosphere only. Never proof.
- Images only from Nigel's own photos, screenshots we capture, or properly licensed sources. Fonts OFL from npm @fontsource.
- Log every file in ASSETS.md with its source and allowed use.
- Screenshots go in light mode inside a paper card. Crop for clarity, nothing cut off mid-sentence.
- Centsible runs on live bank data. Never screenshot it with real numbers. Demo mode only, and only if it proves something the sample runs do not.
- No assets, code or specs from motionin.design or savee.com. Principles in our own words only.
